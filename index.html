How to use the LitBuy spreadsheet

Use one row per size or color you plan to order. Keep the catalog URL and the original seller URL in separate columns so you can retrace the listing if a link changes.

  1. Save the source. Copy the catalog URL and, if the detail page provides one, the original seller URL. Record the product ID, variant, seller price and date checked.
  2. Check the variant. Compare the seller’s measurements with something you already own. Record the chosen size and color before entering the seller link in your agent’s order form.
  3. Review QC photos. If warehouse photos are available, compare the item label, color, measurements and visible condition against your order. Record what you approved or what needs a closer photo.
  4. Record shipping separately. Save the parcel weight, shipping quote and tracking number when available. Update the spreadsheet with the amount you actually paid.

Frequently asked questions

What is a LitBuy spreadsheet?

It is a way to organize product finds and buying-agent orders. This page pairs a HipobuyFind catalog selection with a CSV you can open in Google Sheets, Excel or another spreadsheet app.

Where do the two shopping buttons go?

Both buttons open the HipobuyFind homepage. Individual product links open HipobuyFind listing pages, where you can look for the original seller link.

What should I do if a source link fails?

Open the HipobuyFind listing and check whether the seller URL has changed. Search the catalog by item name or ID if the detail page has moved. Confirm the seller, product and variant before using a replacement link.

What should I record if QC photos are unavailable?

Mark the QC status as pending or unavailable and record which details you still need to confirm, such as the size tag, insole length or a close-up of a seam.
